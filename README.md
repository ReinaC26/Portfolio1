# Reina Chen — Portfolio

A personal portfolio built with React and Vite. Created the 3D island model with Tripo3D and used Three.js to build the interactive rotation and zoom.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Vercel deploys the production build from this repository. The site is available at [reinachenportfolio.vercel.app](https://reinachenportfolio.vercel.app).
